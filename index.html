    Elige un formato y copia o descarga el resultado.

    Añade código Arduino listo para copiar y pegar en este ejemplo. Si cargas varias imágenes, genera un arreglo para cada una.
    Añade código Arduino con un único arreglo de bytes para copiar y pegar.
    Genera una fuente GFXbitmapFont, compatible con una versión modificada de la biblioteca Adafruit GFX. Consulta el proyecto y el ejemplo. El primer carácter ASCII solo se usa si no se especifica un glifo de un carácter para cada imagen.
